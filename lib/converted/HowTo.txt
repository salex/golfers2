This is another scheme to copy the development.sqlite3 database to the containers storage production.sqlite3 database.

The development server can update the database after a creating json files the contain updated models.

Before a deploy the updated the games, rounds, and players to the current filtered files (import) downloaded from the [postgres database.

After a kamal deploy
  docker cp the development.sqlite3 db to the production.sqlite3 in storage.

  deploy the app again for changes/update to complete

Login a root to the droplet

Get the container_id of the golfers2 container

CONTAINER_ID=$(docker ps --filter name=golfers2 --format '{{.ID}}')

docker cp $CONTAINER_ID:/rails/lib/converted/development.sqlite3 $CONTAINER_ID:/rails/storage/production.sqlite3

Exit container and kamal deploy
